## What Chord is

An original macOS window manager in Swift (not a fork of AeroSpace) with its own keyboard grammar, an animated window-resize signature move (Unfold), and a workspace system built around roles rather than app groups.

## Founding idea

**Windows are paper on a desk, not walls of a room.** Chord decides where windows live and how you move between them. It leaves size to you.

## Principles

1. **Size is a decision, never a default.** A window is born as a card (A5, 333 x 471 px; unrounded height 333*sqrt(2) = 470.93) and stays that size until the user decides otherwise. The complete list of things that may make a window big: a fullscreen or zoom command, a mouse resize, a reshape (`Mod+Ctrl+hjkl`), an Unfold (`Mod+0`). (Folding a tiled window is post-v1.) Not an app's preferred size, a layout engine, the Sorter, the Executor, or any agent. A recorded standing wish is still the user's decision.
2. **Places, not app groups.** `1-9` are places, `0` is this window, `` ` `` is the bench. Places answer "what is this for".
3. **One grammar, escalating consequence.** `hjkl` are directions; modifiers set consequence: look (focus), carry (take the window), reshape (size). `Shift` always means "take this with you". Two keys together are a chord (a diagonal).
4. **Preview, then commit; nothing is a one-way door.** Every action has an inverse (step back, undo, remembered homes) and a log line. v1 uses immediate look (no preview overlay, no latch); aim/latch is post-v1.
5. **Predictable by construction.** Decisions are pure functions of window rectangles and a few integers: same layout, same answer; floats never jitter the result. Property tests define "predictable".
6. **Agents propose, the Executor disposes.** Agents emit typed plans from a whitelist. Only the Executor changes windows. The vault (9) is off-limits to agents by construction: the type has no case for it, not a prompt or runtime check.
7. **Floats are the default; tiles are folds.** A floating card is the resting state. Fold-model tiling is post-v1.
8. **Keyboard first, the mouse stays honest.** A mouse resize is a legitimate decision; Chord adapts rather than fights it.
9. **Privacy.** Agents see an app name and a redacted title, never pixels. Password managers are redacted everywhere.

## Non-goals

No auto-maximizing; no layout that fills the screen unless asked. No app or agent resizing. No AI near the vault (9). No hidden state: if Chord moved it, there is a log line and an undo.

## v1 scope

In: nine places plus the bench; the key grammar; immediate look driven by the pure Picker; Unfold (`Mod+0` tap) and Spread (`Mod+0` hold, 700 ms default, configurable); agents as plain files with the rules-first Sorter; Executor with typed plans, whitelist, log, undo; AeroSpace as a pinned backend behind `WorkspaceBackend` until the substrate report (`docs/C6-SUBSTRATE.md`) says otherwise.

Post-v1 (cut): voice, peek, fold-model tiling, workspace templates and template agents, the `Mod+0` palette, the training dojo, the Sorter's model layer, aim/latch look, sibling swap on `Mod+Shift+hjkl`, reshape snapping, cyclical Unfold mode, portrait Unfold, physical-A5 DPI scaling.

## Unfold rules (decided)

- `frame(t, screen, margin)` is pure floating-point; rounding happens only when frames are applied.
- Stops: S0 card, S1 444 x 630, S2 the largest 16:9 box in the screen minus margins; `T_KNOT = 1/phi^2`; smootherstep.
- Landmark fixtures are generated by bisecting `frame()` itself at 1280x720, 1366x768, 1440x900, 2560x1440, 3840x2160, never hand-typed. Reference cross-check: square 0.6504, 4:3 0.7551, 3:2 0.8053, golden 0.8465 (same t at every resolution).
- A press starts or restarts a timer. While it is running, each press advances
  through the fitting stops from the current rect; a press mid-ease retargets
  without stacking animations. After expiry, the next press starts again at the
  smallest fitting stop (normally the A5 card). The progression is A5 when it
  fits, then square, 4:3, 3:2, golden, and 16:9; the card stop is skipped when
  it does not fit the visible frame. The pure `UnfoldAnimator` owns this
  press/timer state; window application remains outside the core.
- The step timer is 600 ms by default and configurable; it is distinct from
  `frame()` geometry. Non-16:9 screens letterbox in the largest 16:9 box.
  Portrait screens are unsupported. High DPI is not pursued.
