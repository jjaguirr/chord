# GLOSSARY.md

**note** — a single key press.
**chord** — two keys held together; a diagonal.
**diagonal chord** — two direction keys held together, e.g. `h+k`.
**opposing chord** — `h+l` or `j+k`; cancels to zero, reserved.
**roll** — two sequential presses, not a chord.
**arpeggio** — held-key repeat.

**look** — move focus. **carry** — take the window with you.
**reshape** — change a window's size.
**aim** — preview a look target before committing.
**unfold** — grow the focused window along the harmonic path.
**spread** — group cards by target place as a preview.

**place** — a workspace, identified by role.
**bench** — the system's undecided pile; agents may re-sort.
**vault** — place 9. Agents blind, user-only exit. Fixed.
**redacted tier** — place 4. Agents see app + redacted title.

**card** — the resting window size, 333 × 471 px.
**home** — a window's remembered frame and place; the undo target.

**sorter** — the first agent; decides where windows belong.
**executor** — the only component allowed to change windows.
**plan** — typed data an agent emits; the Executor applies it.
